# Phase 18 architecture

The modular monolith and existing collector, managed archives, paper accounts, approved
strategies, risk engine and Phase12–17 journals remain. No original model/checkpoint policy
is replaced. New event research consumes the shared genuine frame; it is not a new collector.

Storage admission proves200 GiBcollector+100 GiBexperimental against measured all-file service
usage and actual allocatable filesystem capacity, keeping100 GiBprotected free plus 8 GiB
rotation/block-allocation headroom and 64 GiB shared-workload growth headroom in the plan.
Existing managed-store runtime checks enforce the configured100 GiB floor and all-tier hard
budgets. No300 GiBpreallocation or AWS resource change occurs. New advisory tier allocations
sum to approved budgets and do not imply deletion authorization. Retention dry-run/audit
plans verify sealed originals, gzip hashes/restoration/completeness, age and process references;
there is no deletion method or activation in this release.

IndependentEventResearch runs as a bounded asynchronous consumer in the experimental service.
It interprets exact event rules, acquires at most two genuine public external requests for a
selected event per five-minute refresh, and records full evidence with actual receipt times.
The first functioning new model is an exact Binance daily-Low barrier research probability.
It distinguishes final-minute Low paths from terminal Close prices and preserves the old
ambiguous-noon quarantine. Its zero-log-drift continuous first-passage approximation uses
720 closed returns, complete elapsed rule-window candles and last-observed-price timing.
It is **uncalibrated**, with[0,1]uncertainty, and has no operational order authority.
Weather residual/ensemble and economics-vintage requirements remain explicit; genuine context
alone cannot generate an invented probability. Existing NFL prospective evidence is preserved.

Each EventProbabilityStudy is an immutable record in the existing managed archive, binding
source frame, market/book/rules, external raw evidence/hash/availability, model/code/dataset
versions, prospective DomainForecast, two policy assessments and capacity scenarios. A bounded
lossless verified checkpoint supports idempotent ambiguous-write recovery and refuses code or
integrity mismatches. No account API is exposed to the consumer. Missing labels/failed sources
remain explicit; original predictions are never revised.

After event close, bounded scheduled checks require native finalized settlement proof AND
replay of the exact complete independent reference window before recording an outcome.
Disagreements remain unresolved. Per-event score arithmetic is descriptive only; headline
calibration remains withheld until verified independent cohorts suffice. Restarted outcome
records are not silently promoted to current proof authority.

Event-disjoint validation quarantines parent aliases and groups seen across training,
validation and heldout, checks training-label availability, and reuses the existing strict
100 training/100 held-out calibrated-event contract. Quote marks never become outcomes.

Evidence convergence separately requires calibrated independent forecasts, reviewed source
lineages, executable costs/depth, uncertainty, rules, risk and strategy admission. Different
providers can share upstream evidence. Both throughput and conviction assessments are
research-only. Capital500/1 k/10 k/100 k/1 Mscenarios are nonlinear displayed-liquidity stress
calculations, not accounts, fund increases, fills or proportional profit claims.

`monitor --view operations` reports actual new budgets, tiers, growth and source health.
`monitor --view edge` prioritizes independent event research when available, retaining the
legacy mark view as fallback. Narrow views preserve both equities, stops and live-config
verification; stale/degraded observations cannot display current research authority.
