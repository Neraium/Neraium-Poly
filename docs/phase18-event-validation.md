# Phase 18 event-disjoint qualification

The new validator admits only independently replayed prospective forecasts and independently
verified native/reference outcomes. Defaults deny; declarations and matching hashes alone
cannot prove source truth. Parent aliases with inconsistent dependency groups quarantine,
as do all groups present both before and inside heldout. Repeated forecasts/tokens from
one parent never increase independent sample size. Training labels must be available at
the training boundary; heldout models must be frozen before the heldout boundary.
Models/domain/feature/contract cohorts remain separate and reuse unchanged100 training /
100 held-out independent-event requirements. The caller must predeclare split boundaries;
the framework does not optimize them against outcomes. No validation result grants orders
or certification.

The earlier20 temporalheldoutmark episodes are **not**20 independent event outcomes.
Monetary marks remain useful execution research but cannot become terminal binary labels.
Current settlement qualification preserves250 historical groups,51 officiallyverified outcome
groups,47 chaincorroborated groups,0 historical-depth-qualified groups and 0 point-in-time-qualified
training/heldout events. No missing historical book is reconstructed from present prices.

The new crypto forecasts are prospective research observations. Different thresholds and
YES/NO tokens sharing parent1323373 are dependent. Raw numerical independence from Polymarket
features does not establish independent event samples, calibrated probabilities, independent
source confirmations or profitable trading. Until terminal proof, parent review and sufficient
homogeneous chronological samples exist, headline Brier/logloss/reliability/confidence
intervals and forecasting superiority remain unavailable. Fixture200-event cohorts test the
gate and are never authentic sample counts.

New outcome checks preserve original forecasts and require finalized Polymarket native proof
plus an exact independently fetched Binance event-window match. The source window remains
retrieved-now evidence; it is not backdated into prediction features. Missing, disputed or
contradictory proof leaves the forecast unresolved. Checks are rate bounded and rotate pending
checks rather than letting one missing settlement starve all others. Active checkpoint caches
are bounded; all committed studies remain in the append-only archive. Research code changes
fail checkpoint restoration rather than silently resetting a model's history.
