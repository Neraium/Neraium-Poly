# Delivery roadmap

0. Inspect checkout, Citadel state and host resources.
1. Freeze v1 contracts, module boundaries, fixtures and test commands.
2. Implement data, evidence and risk in isolated worktrees.
3. Implement strategy and execution against reviewed interfaces; build dashboard.
4. Integrate API, deterministic scenario runner and persistence.
5. Certify replay, failure recovery, idempotency, risk boundaries and browser flows.
6. Audit dependencies, document limitations, commit and push verified implementation.

Future research: richer event ontology, independently labeled relationships, exchange-specific fees, calibrated models with real held-out labels, PostgreSQL multi-process reservations, queue-aware maker simulation, multi-exchange adapters. Live execution requires a separate release and explicit authorization.
